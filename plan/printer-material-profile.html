Deferred: Printer / material profile

Idea

Add named profiles (e.g. printer_profiles.json) capturing per-printer/material limits so the skill can pick clearances, wall thickness, and support rules automatically:

{
  "printer": "Creality K1",
  "nozzle": 0.4,
  "material": "PETG",
  "layer_height": 0.2,
  "max_overhang": 50,
  "max_bridge": 15,
  "min_wall": 1.2,
  "sliding_clearance": 0.3,
  "hole_compensation": 0.2,
  "elephant_foot": 0.2
}

Why deferred

Only one printer/material combination is in use today. A profile file is config for a value that doesn't currently vary — adding it now is a config surface with a single caller, which is exactly the kind of unrequested abstraction the skill's own construction rules warn against. The existing parameters.json (see assets/parameters.example.json) already carries a clearances section that covers today's need.

When to build it

Once a second printer or material is actually in rotation, or the same clearance/wall numbers start getting hand-copied across multiple parts.

What it touches

  • assets/parameters.example.json — add an optional printer_profile reference field.
  • assets/freecad-parametric-template.FCMacro — load the referenced profile and merge its clearance defaults under user-supplied clearances.
  • SKILL.md §"Tool and format selection" — document how a profile is selected/overridden.
