Deferred: Strength / load check

Idea

Before modelling a load-bearing part (phone holder, wall mount, tool holder), record as parameters: load direction, estimated weight, load arm/lever length, print layer orientation relative to load, safety factor, and minimum wedge/rib thickness derived from that factor.

Why deferred

This is a structural-engineering estimate (bending stress vs. layer adhesion strength), not a geometry check a short script can verify generically — it needs material-specific strength data and a real beam/cantilever calculation per part shape. Building a generic "safety factor" field without the calculation behind it would be a fake abstraction: config for a number nobody computes.

When to build it

When an actual load-bearing part fails in use (cracks, sags, layer-separates), or before printing a part where failure would be costly/dangerous (long cantilever, wall-mounted weight).

What it would touch

  • references/engineering-checklist.md §1 "Requirements contract" — add load direction/weight/arm as required questions for load-bearing parts specifically (not all parts).
  • A short reference note with layer-orientation-vs-load rules of thumb (load along layers is weaker than across), not a full FEA integration.
