Deferred: SVG structural validator

Idea

Mirror scripts/validate_dxf.py for the review SVG: valid XML with a declared viewBox, no embedded raster (<image>) standing in for real geometry, three distinguishable projections present, visible dimension/label text, and a revision mark.

Why deferred

SVG in this skill is explicitly the human review surface (SKILL.md §"Tool and format selection": "Use SVG as the primary review drawing... DXF as the mandatory editable engineering drawing"). DXF is the engineering source of truth and is already strictly validated; the SVG's correctness is checked by a human looking at it during the approval gate the workflow already requires. Duplicate automated structural validation adds a second checker for a file whose only job is to be visually read once.

When to build it

If SVGs start being generated unattended (skipping the human-approval gate) or if an approved SVG and its paired DXF are later found to have silently disagreed.

What it would touch

  • A new scripts/validate_svg.py, structured like validate_dxf.py (parse XML, check viewBox, absence of <image>, presence of expected text strings).
  • SKILL.md §"Validation gates" — add alongside the DXF/STL/STEP/projection checks.
