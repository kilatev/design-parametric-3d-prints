design-parametric-3d-prints — overview

This document describes the design-parametric-3d-prints skill for someone deciding whether to use it. It does not cover implementation details (scripts, functions, file formats); see SKILL.md and references/ for that.

1. Scope

The skill produces a parametric CAD model for a functional part intended for FDM 3D printing, not a plausible-looking image. Before any 3D geometry is built, it produces a dimensioned drawing. Every dimension is a named, traceable parameter rather than a number typed once into a picture. Fit, bed contact, and printability are checked against the exported geometry, not assumed from appearance.

2. When to use it

Use itSkip it
Functional parts: holders, organizers, mounts, adapters, enclosures, multi-part assemblies — anything with a fit, a clearance, or parts that must move or separate. One-off decorative shapes with no critical dimensions and no assembly. The drawing/validation process adds no value there.

3. Inputs

  • Text description — dimensions and requirements in words.
  • Reference photo or screenshot, including a slicer screenshot showing a print failure — the skill reads geometry evidence from it: colliding parts, overhangs, clearances, even screw head shape.
  • Existing CAD or drawing to revise.

5. Edge treatment rule

Not every edge is treated. The skill proposes a chamfer or fillet only where it changes comfort, assembly, or strength, and stays silent otherwise.

Proposes a treatmentLeaves untreated
Edges that are gripped or handled (fillet, for comfort)Fully internal/hidden faces never seen or touched
Hole or slot entry edges (chamfer, to guide insertion)Edges carrying an already-fixed critical clearance dimension
Exposed outer corners that could be bumpedThe bed-contact edge or a support-wedge contact edge
Load-bearing internal corners (fillet, to reduce crack risk)Features smaller than the printer's minimum feature size
Steep overhang-start edges (chamfer, to print support-free)

6. Repeated features

When one shape appears more than once — a mirrored pair, four wheels, table legs, screw bosses — it is modelled once and every copy is placed by position, rotation, or mirror. Copies are never hand-duplicated or hand-rotated, which removes the common "correct angle, wrong sign" error from manual copies.

8. Print-in-place joints

A print-in-place joint prints already assembled: two parts with a functional gap between them, with no assembly step afterward.

Implemented: pin-in-sleeve
A pin rotating inside a sleeve — a hinge, swivel, or rotating joint. A grid of test pairs at different clearances can be printed before committing to the final joint (see §9).
Available on request (designed case by case, not a ready preset)
Ball-and-socket (multi-axis joint) · living hinge (a thin flexing membrane instead of a gap) · multi-link chain or snake-arm (repeated pin-in-sleeve or ball-socket units) · self-retaining pin with opposed helical grooves (resists axial drift without a precisely tuned clearance) · printed cantilever spring (for a latch or clip) · ratchet and pawl · herringbone gear bearing (meshing teeth instead of a captured ball — more tolerant of FDM's layer resolution; a printed ball/roller bearing is generally discouraged in favor of a cheap bought bearing).

The skill applies these constraints on its own and flags them where relevant: the joint's rotation axis must be vertical during printing; sticky materials such as PETG need looser clearances than PLA; a plastic-on-plastic joint wears faster than a metal one, which matters for high duty-cycle mechanisms.

9. Test coupons

For a fit-critical clearance, a small plate with several trial clearance values (or a small grid of pin/sleeve pairs for a print-in-place joint) can be printed before the full part. Measure the result, fix the chosen clearance, then print the full part.

10. Workflow

  1. Description or photo is converted into a table of named dimensions.
  2. A preliminary drawing (front, top, right-side views) is produced for approval. Work pauses here unless an uninterrupted run was requested.
  3. Once approved, the 3D model is built — each functional part as a separate, movable block.
  4. The exported geometry is checked for printability: no floating blocks, correct bed contact, fits the declared build volume.
  5. Final files are delivered (see §11).

12. Revisions

A material geometry change gets a new, explicitly labelled revision. Every deliverable is stamped with its revision, and a manifest lists which files belong to which revision — old and new deliverables cannot be mixed up.

14. Quick mode

None of the above requires formally installing the skill first. For a small or repeat job, describing the request in the style of §13 gets the same workflow without any setup step.
