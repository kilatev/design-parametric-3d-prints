design-parametric-3d-prints — обзор

Документ описывает скилл design-parametric-3d-prints для тех, кто решает, использовать ли его. Здесь нет деталей реализации (скрипты, функции, форматы файлов) — за этим см. SKILL.md и references/.

1. Назначение

Скилл строит параметрическую CAD-модель функциональной детали для FDM-печати, а не правдоподобно выглядящую картинку. Прежде чем строить 3D-геометрию, он готовит чертёж с размерами. Каждый размер — именованный, прослеживаемый параметр, а не число, вписанное однократно в рисунок. Посадка, контакт со столом печати и печатаемость проверяются по экспортированной геометрии, а не принимаются на веру по внешнему виду.

2. Когда использовать

ИспользоватьНе нужно
Функциональные детали: держатели, органайзеры, крепления, переходники, корпуса, сборки из нескольких частей — всё, где есть посадка, зазор или части, которые должны двигаться или разделяться. Разовые декоративные формы без критичных размеров и без сборки. Процесс чертежа и проверок там ничего не даёт.

3. Что подать на вход

  • Текстовое описание — размеры и требования словами.
  • Референсное фото или скрин, включая скрин слайсера с ошибкой печати — скилл читает по нему геометрические факты: столкновения частей, нависания, зазоры, даже форму головки винта.
  • Существующий CAD или чертёж для доработки.

5. Правило обработки кромок

Обрабатывается не каждая кромка. Скилл предлагает скругление или срез только там, где это меняет удобство, сборку или прочность, и молчит в остальных случаях.

Предлагает обработкуОставляет без обработки
Кромки, за которые держат (скругление — для комфорта)Полностью внутренние/скрытые грани, которые никогда не видны и не трогаются
Входные кромки отверстий и пазов (срез — направляет при вставке)Кромки с уже зафиксированным критичным размером зазора
Выступающие внешние углы, которые могут задетьКромка контакта со столом или с опорным клином

Резкие кромки начала нависания (срез — для печати без поддержек)

6. Повторяющиеся элементы

Когда одна форма встречается больше одного раза — зеркальная пара, четыре колеса, ножки стола, бобышки под винты — она моделируется один раз, а каждая копия задаётся положением, поворотом или зеркалом. Копии никогда не дублируются и не поворачиваются вручную — это убирает типичную ошибку «угол верный, знак перепутан» при ручном копировании.

8. Механизмы, печатающиеся уже собранными

Такой узел печатается уже собранным: две части с функциональным зазором между ними, без этапа сборки после печати.

Реализовано: палец во втулке (pin-in-sleeve)
Палец, вращающийся внутри втулки — петля, поворотный узел или шарнир. Перед финальной печатью можно напечатать решётку пробных пар с разными зазорами (см. §9).
Доступно по запросу (проектируется индивидуально, не готовый пресет)
Шарнир шар-в-гнезде (многоосевой) · гибкая перемычка (living hinge) — тонкая сгибаемая мембрана вместо зазора · многозвенная цепь или «змейка» (повторяющиеся узлы палец-во-втулке или шар-в-гнезде) · самозацепляющийся штифт с встречными винтовыми канавками (противостоит осевому смещению без точной подгонки зазора) · печатаемая пружина-балка (для защёлки или клипсы) · защёлка с зубом (ratchet/pawl) · шевронный шестерёнчатый подшипник (зацепление зубьев вместо захваченного шарика — терпимее к разрешению слоя FDM; печатаемый шариковый/роликовый подшипник обычно не рекомендуется в пользу дешёвого готового подшипника).

Скилл сам учитывает и, где нужно, отмечает следующие ограничения: ось вращения узла должна быть вертикальной при печати; липким пластикам вроде PETG нужны бо́льшие зазоры, чем PLA; пластиковый узел изнашивается быстрее металлического, что важно для механизмов с частой эксплуатацией.

9. Тестовые пластинки

Для критичного по посадке зазора можно напечатать маленькую пластинку с несколькими пробными значениями зазора (или маленькую решётку пар «штифт-втулка» для узла печатается-собранным) перед печатью всей детали. Измерить результат, зафиксировать выбранный зазор, затем печатать деталь целиком.

10. Процесс

  1. Описание или фото переводится в таблицу именованных размеров.
  2. Готовится предварительный чертёж (виды спереди, сверху, справа) на согласование. Работа останавливается здесь, если не запрошен непрерывный процесс.
  3. После согласования строится 3D-модель — каждая функциональная часть как отдельный подвижный блок.
  4. Экспортированная геометрия проверяется на печатаемость: нет висящих в воздухе блоков, правильный контакт со столом, деталь вписывается в заявленный объём печати.
  5. Передаются финальные файлы (см. §11).

12. Ревизии

Существенное изменение геометрии получает новую, явно помеченную ревизию. Каждый файл маркируется своей ревизией, а манифест указывает, какие файлы относятся к какой ревизии — старые и новые файлы невозможно перепутать.

13. Примеры запросов

Сценарий: обычная деталь с размерами
«Нужна подставка под телефон под углом 60°, паз шириной
80 мм, глубина паза 10 мм, устойчивое основание.
Материал: PLA.»
Сценарий: по референсному фото
«Вот фото корпуса, куда должен встать этот блок питания.
Нужна крышка с вырезом под провод и защёлкой, чтобы не
выпадала.»
Сценарий: со стандартным компонентом
«Нужен держатель для катушки нити с подшипником 608
внутри, чтобы катушка свободно вращалась.»

«Нужен органайзер для мелких деталей в системе Gridfinity,
стандартная база 42 мм.»
Сценарий: с механизмом «печатается собранным»
«Нужна крышка на шарнире, которая печатается уже
подвижной, без сборки после печати — открывается на 90°,
материал PLA.»
Сценарий: с проверкой посадки перед полной печатью
«Перед печатью всего корпуса напечатай сначала маленькую
тестовую пластинку с несколькими вариантами зазора для
защёлки, чтобы я выбрал подходящий.»

14. Быстрый режим

Ничего из вышеперечисленного не требует формальной установки скилла. Для мелкой или повторной задачи описание запроса в стиле §13 даёт тот же процесс без какой-либо настройки.
